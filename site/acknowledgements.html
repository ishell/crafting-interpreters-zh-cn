Acknowledgements

当第一本《游戏编程模式》售出时，我想我总算有资格自称作者了。可真正安心戴上这顶帽子，还花了好些时间。谢谢每一位买了第一本书的读者，也谢谢把书带到其他语言的出版方与译者。是你们给了我信心，相信自己扛得住这种体量的项目。嗯，再加上我严重低估了自己到底跳进了怎样一口坑——那就算我自己的事儿了。

技术写作有一种特别的恐惧：写错了。测试和静态分析只能帮到这一步。代码和文字一旦印成墨迹落在纸上，就改不了了。我深深感谢在本书的 开源仓库 里提交 issue 与 pull request 的许多人。特别要谢谢 cm1776——他委婉而精准地开了 145 个 issue，指出了成百上千处代码错误、笔误，以及含糊不清的句子。因为你们，这本书更准确，也好读得多。

我也感谢文字编辑 Kari Somerton：她硬着头皮钻进一堆计算机科学行话，还适应了一套陌生的工作流，只为修好我那些语法错误和风格上的前后不一。

当疫情把所有人的生活翻了个底朝天时，有不少人写信告诉我：这本书成了他们难得的、有益的分心。这本我写了六年的书，构成了我人生故事里的一章；感谢那些联系过我的读者，让这一章更有分量。

最后，最深的谢意献给妻子 Megan，以及女儿 Lily 和 Gretchen。你们耐心忍受了我埋进这本书的那些时光，还有写作时的焦躁。困在家里，我最想和你们一起。
